Mr Mobile - موقع تعريفي لمحل موبايلات

هذا موقع ويب تعريفي (Landing Page) لمحل موبايلات متخصص في صيانة أجهزة أندرويد وبيعها.

التقنيات المستخدمة:
- HTML5
- CSS3
- JavaScript (Vanilla فقط بدون أي Framework)

خصائص الموقع:
1. تصميم عصري وبسيط يناسب محل موبايلات
2. ألوان مريحة (درجات أزرق / أسود / أبيض)
3. متجاوب مع جميع الأجهزة (موبايل، تابلت، لابتوب)
4. استخدام أيقونات Font Awesome
5. تأثيرات CSS و JavaScript بسيطة
6. نموذج اتصال مع التحقق من الصحة

محتوى الموقع:
- Header مع شعار و قائمة تنقل
- قسم رئيسي (Hero) مع عنوان جذاب و أزرار اتصال
- قسم الخدمات مع 6 خدمات رئيسية
- قسم عن المحل مع ميزاته
- قسم تواصل معنا مع معلومات الاتصال ونموذج
- Footer مع معلومات إضافية

كيفية التشغيل:
1. فتح ملف index.html في أي متصفح حديث
2. أو رفع الملفات على أي استضافة ويب

ملاحظات:
- الصور المستخدمة هي من موقع Unsplash للعرض فقط
- يمكن استبدالها بصور حقيقية للمحل
- الأرقام والعناوين المذكورة هي لأغراض العرض فقط
- يمكن تعديل أي جزء من الكود ليناسب احتياجاتك
